# Mylange

Mylange is the Myriware in-house programming language, aimed at providing a versitile,
commonly-understoond language for all at Myriware to use. It is also accessable to the
community. More information can be found at [Myriware](https://myriware.space/solution/mylange).

This repo is the developing C++ based approach at running the script (whereas the Python
method will soon be phased out). This repo is automatically formated for using Visual Studio 2026.
